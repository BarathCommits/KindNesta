## Quick start for suppliers

1. Open `partner-product-template.csv` in Google Sheets / Excel  
2. Read `SUPPLIER-FILL-GUIDE.md`  
3. Keep the header row — **one row per SKU**  
4. Leave columns blank when they do not apply  
5. Optionally complete `partner-product-evidence.csv` for green claims / stronger scoring  
6. Attach photos + any certificate PDFs  
7. Return files to **kindnesta@proton.me**

**EU claim rule:** no generic “eco-friendly / green / sustainable / climate neutral” without proof. Prefer specific claims with % and scheme names when you have them.
